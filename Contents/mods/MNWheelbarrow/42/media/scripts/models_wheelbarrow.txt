module Base
{
    /*
     * Modelo do carrinho quando largado no chao.
     *
     * POR QUE module Base E NAO module MNWheelbarrow:
     * todos os modelos do jogo base vivem em `module Base` -- models_items.txt
     * inteiro e Base -- e nenhum item vanilla referencia modelo qualificado por
     * modulo. Definir o modelo num modulo proprio e referencia-lo pelo nome nu
     * e um caminho sem nenhum precedente no jogo, e o modelo simplesmente nao
     * aparecia no mundo, sem erro no log. O nome carrega o prefixo MNWheelbarrow
     * para nao colidir com outro mod dentro do namespace compartilhado.
     *
     * O mesh original tinha 4 texturas PBR de 4096x4096 embutidas (21.7 MB).
     * O PZ so usa mapa difuso, entao o payload embutido foi removido; a
     * geometria ficou identica (2240 vertices, mesmos 393 nos).
     *
     * SCALE: comparar so a bounding box do mesh NAO funciona. O tamanho final e
     *
     *     bbox do mesh  x  Lcl Scaling do no Model  x  scale deste script
     *
     * e o Lcl Scaling difere brutalmente entre os arquivos:
     *
     *     Log vanilla   bbox 30.932  x  Lcl 0.02778  x  0.4  =  0.3437
     *     este mesh     bbox  1.900  x  Lcl 100.0            <- 100x embutido
     *
     * O vanilla embute a conversao de unidade no Lcl Scaling (91.44/2.54 = 36,
     * e 1/36 = 0.02778). Este arquivo veio de uma ferramenta em centimetros com
     * a unidade nao aplicada, entao carrega 100x. Ignorar isso me fez calcular
     * scale = 6.5, que renderizou o carrinho 3593x grande demais -- ocupando
     * varios quarteiroes.
     *
     * 0.0057 e o valor calibrado em tela, em tres passadas: 0.0025 ficou tres
     * vezes pequeno demais, 0.0075 ficou 20% grande demais, 0.006 ainda pedia
     * mais 5%. Dobrar o numero dobra o tamanho renderizado.
     *
     * ALTURA: o mesh foi deslocado 0.380 no eixo Y (ver
     * assets/tools_fbx_shift_y.py) para a base ficar em Y = 0 em vez de a
     * origem ficar no centro. Os modelos vanilla sao centrados -- medi o Log e
     * o ToolBox_Ground e ambos tem a origem a 50% da altura -- e o engine
     * assenta a origem no chao, entao todo modelo afunda metade da propria
     * altura. Num tronco deitado isso e imperceptivel; num carrinho alto o
     * resultado era metade dele enterrada.
     */
    model MNWheelbarrow_Ground
    {
        mesh = WorldItems/Wheelbarrow,
        texture = WorldItems/Wheelbarrow,
        scale = 0.0057,
    }
}
